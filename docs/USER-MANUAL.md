# Aurabot 使用手册（给不懂技术的你）

> 大肥鱼的「家」在 DeepSeek Harness（下面简称 DSH）里，QQ 是她的手机。
> 所有设置都在 DSH 左侧栏「自动化任务」下面的 **Aurabot** 里。

工作台按用途分组。窄窗口会把左侧导航移到顶部，右上角可以查找功能或切换运行模式。

- **心智**：她现在、记忆、关系、念头与行动、人格卡、人格与自我、心智设置。
- **QQ 会话**：连接、回复规则、聊天模型、语音识别、白名单与权限、QQ 空间。
- **表达与创作**：语音合成、表情包、生图、翻唱、生视频。生视频使用本地脚本，收到视频时仍只显示消息提示。
- **系统**：日志、备份与恢复、安全防护、浏览器、本地接口、关于。
- **扩展**：模块管理与模块市场。桌宠、抖音、小黑盒会在对应模块启用后出现。

## 一、第一次使用（大约 10 分钟）

第一次打开 Aurabot 会自动出现 **设置向导**，跟着走 4 步就行。以后想重新走，可以在「连接」标签点「重新走一遍设置向导」。如果升级前已连上 QQ 且机器人号核对通过，向导会显示「使用现有连接，进入面板」，点它即可保留当前设置并完成向导。

### 1. 你们的 QQ 号
- **机器人 QQ 号**：给大肥鱼用的号，**一定要用小号**。
- **你的 QQ 号（主人）**：操作电脑这些只听主人的。

### 2. 接 QQ 网关
SnowLuma 没有 macOS 版，在 Mac 上用 OrbStack（或 Docker Desktop）跑它的 Linux 镜像：
1. 装好 [OrbStack](https://orbstack.dev)，用 [SnowLuma 官方的 docker-compose.yml](https://github.com/SnowLuma/SnowLuma.Docker.Framework) 启动（`docker compose up -d`）。
2. 打开它的远程桌面（`http://127.0.0.1:6081`），登录机器人号；第一次启动时日志里会打出远程桌面和控制台的密码。
3. 在 SnowLuma 控制台（`http://127.0.0.1:5099`）里看 OneBot 的正向 WebSocket 地址和令牌，一般是 `ws://127.0.0.1:3001`，把它们填进向导。

NapCat、LLOneBot、Lagrange 等任何 OneBot v11 实现也可以。插件只连接，不启动、不注入任何东西。

### 3. 连上机器人号
点 **连接**。插件连上后会先核对登录的是不是机器人号，不是就断开；看到「连上了：大肥鱼（机器人号）」就成功了。

### 4. 先试运行，再正式上线
1. 推荐选 **先试运行**：她会照常思考，但只把要说的话写进日志，**不会真的发出去**。
2. 用你的主号给机器人号发一句「在吗」，然后去「日志」标签看她本来要回什么。
3. 觉得没问题，就在右上角的运行模式菜单选 **正式模式**，她就正式上线了。

- **QQ 会话放在哪**：默认在 `~/Aurabot/qq-chats`，想放到别处就在「连接」页填完整路径（比如 `/Volumes/外接盘/Aurabot/qq-chats`）。

## 二、日常怎么用

| 想做的事 | 去哪里 |
|---|---|
| 让她暂时别说话 | 在右上角的运行模式菜单关掉 **启用 AuraBot** |
| 只看她想说什么、不真发 | 在右上角的运行模式菜单选 **试运行** |
| 把她拉进一个群 | 先在 QQ 里拉机器人号进群，再去 **QQ 会话 → 白名单与权限**，把群号加进「群白名单」，保存 |
| 允许某个朋友私聊她 | **白名单与权限** → 私聊白名单，加上对方 QQ 号 |
| 改她的人格卡（她是谁、怎么说话） | **心智 → 人格卡**：直接改文字，保存后下一句起生效（会存一个版本） |
| 换一套人格 | **心智 → 人格卡**：选中一个，点「设为当前」 |
| 看她的性格、确认她「本来的样子」、退回旧版本 | **人格与自我** 标签 |
| 看她现在累不累、困不困、饿不饿、什么心情；喂她、叫醒她 | **她现在** 标签 |
| 看她在想什么、想做什么、等你批的权限 | **心智 → 念头与行动** |
| 看她记得什么、删掉某条记忆 | **记忆** 标签 |
| 看她和每个人、每个群的关系 | **关系** 标签 |
| 调她的年龄、生日、时区、「专一」和各种参数 | **心智设置** 标签 |
| 让她在群里话多一点或少一点 | 插不插话由她自己决定（看性格、心情、话题、在场的人）。整体多爱接话在 **心智设置 → 社会认知与关系**；某个群不想让她主动插话，在群里发 `/quiet`，或在 **QQ 会话 → 回复规则** 按群设成 0 |
| 在私聊里让她帮你操作电脑 | **白名单与权限** →「主人私聊的权限」选「完整」（默认就是） |
| 换声音 | **表达与创作 → 语音合成**：选音色，点「生成」试听；也可以用「翻唱」页导入的 RVC 音色给语音条变声（说话和唱歌同一个声音） |
| 管理表情包 | **表情包** 标签：可以改名字、删除、上传新的 |
| 让她马上写一篇空间日记 | **QQ 会话 → QQ 空间** →「现在写一篇」 |
| 看她花了多少 token / 多少钱 | **概览** 的「今日活动」里点「查看用量」，可看今日 / 昨日 / 近 7 天 / 近 30 天和各模块的用量与花费（按 DeepSeek 官方价估算，空闲时段表价、高峰翻倍；价格可在 `config.usage.pricing` 改） |
| 看她和某个人聊了什么 | DSH 左侧栏的「Aurabot · QQ」工作区，点对应的会话 |
| 插一句话帮她回 | 在那个会话里直接打字，她这一轮的回复也会发到 QQ |

### 在 QQ 里直接管她

你（主人）在私聊或白名单群里可以用下表的管理命令，总开关关闭时也能用。私聊直出生图有单独的运行条件。

| 命令 | 作用 |
|---|---|
| `/silent`（`/闭嘴`） | 在这个聊天里先不说话；`/silent 30` 是安静 30 分钟 |
| `/active`（`/说话`） | 解除闭嘴 |
| `/quiet` `/chatty` `/normal` | 这个群里：不主动插话 / 更想接话 / 恢复默认 |
| `/model`（`/模型`） | 看能用的模型；`/model 2` 或 `/model 名字` 换，`/model 默认` 跟随 DSH |
| `/status`（`/状态`） | 看她现在的状态 |
| `/mood`（`/心情`） | 看她现在的心情和身体 |
| `/投喂 食物名`（`/喂`） | 给她吃的（都是虚拟的，不涉及付款） |
| `/diary`（`/日记`） | 马上写一篇空间日记 |
| `/remember 内容`（`/记住`） | 让她记住一件事 |
| `/reset`（`/重开`） | 这个聊天重新开始 |
| `/off` `/on` | 关掉 / 打开总开关 |
| `/help` | 看全部命令 |
| `/画图 画面描述` | 仅主人与机器人 QQ 的好友私聊可用，命令和描述之间留一个空格 |

**私聊直接生图**。先启用内置「生图」模块，在「本地接口」页配置并开启 `image.mjs`，打开总开关并退出试运行或调试模式。在 QQ 好友私聊发送 `/画图 一艘雨天靠岸的小船` 后，Aurabot 将描述原样提交给本地脚本，尺寸沿用生图设置。画好只发到该私聊，失败会在原私聊显示简短状态。普通聊天仍由她决定是否调用生图工具。

命令和成品留在 QQ 私聊，Aurabot 会将其排除在提供给聊天模型的 QQ 历史、引用和合并转发之外，也不会收录到心智、图库或空间日记。QQ 和本地生图服务有各自的存储设置。

## 三、她会做的事

- **聊天**：短句、口语，想说的多会拆成几条，每条之间像真人一样停顿一下。
- **群聊**：被 @、有人回复她、或者叫她的名字和小名（她改名后跟着变；「聊天」页还能加别的叫法）时会回，群聊安全刹车和闭嘴设置仍然生效。一个人 @ 或引用她时，她的第一条回复会引用那条消息并真正 @ 对方；多人同时找她时不猜要 @ 谁。其他时候插不插话由她自己：爱不爱说话的性格、此刻的心情和精力、群里聊的和她记得的事或爱好有多相关、在场的人和她多亲近；看完群里在聊什么，她也可以决定不说话。
- **看引用**：别人引用一条消息时，她会去查被引用的内容（谁说的、正文、几张图/表情），私聊和群聊都能看到；引用的是她自己以前说的话时会标成「你」。引用里的图片和表情包也会作为附件给她看（最多 2 张）。查不到时她会知道「这条引用没读到」，可以如实说没看到，不会装作看见了。

- **跨会话查聊天和记忆**：她在任何聊天都可以按需查已保存的其他群聊和别人私聊的原话、想起整理后的经历。近况会按相关设置带入，原话通过按日期翻看或搜本地流水取得。你们的私聊原文只在原会话可查。在「心智 → 记忆 → 私聊隐私」关闭「跨会话使用日常片段」后，日常片段也只在你们的私聊可用。想让她在指定群或私聊提起一件私下经历，在「记忆」里点「允许分享」，填写能说的话和群号或对方 QQ 号。保存后可以在记忆列表撤回。
- **在群里 @ 人**：她 @ 谁，对方会真的收到 QQ 的 @ 提醒。她按群名片和 QQ 昵称找人；对不上、或者群里有两个同名的，她就不 @，只把名字当普通文字发出去。注意：你手机上给好友设的**备注**她看不到。比如你备注叫「小明」、他在群里叫「Luna」，你说「去 @小明」她是找不到的，告诉她群名片或 QQ 号就行，对不上时她也会跟你说没 @ 到。
- **替你去别的群 / 私聊说话**：在和她的私聊里说「去 XX 群说一声……」「跟 XX 私聊说……」，她会过去说（对方要在白名单里）。下次那个群再有人找她时，她记得自己刚才在那里说过什么，能接上话。
- **发文件**：在和她的私聊里说「把 XX 文件发给我」就行，她也能按你说的发给白名单里的人或群。她只能发 QQ 工作区（她平时写文件的地方）和你在「聊天」页「发文件」里额外加的目录中的文件；单个文件默认最大 50 MB；每次发了什么会写进日志。这个功能在「聊天」页可以关掉。
- **危险命令确认（可选，默认关）**：面板「聊天」页打开后，她在私聊里要执行删除根目录、格式化、关机、下载后直接执行这类终端命令之前，会先发 QQ 私聊问你；回复「确认」才执行，回复「取消」或 60 秒没回就拦下，她也会把实际要执行的命令原文如实告诉你。群聊和其他人的会话没有本地终端工具，不会碰到这个开关。
- **看图**：支持视觉的模型可以看别人发来的图片和表情包；转发给她的聊天记录（合并转发）她也能展开看。她画完图后，支持视觉的聊天模型也能收到图片附件；大图需要本机 ffmpeg 缩图，缩图或附件服务不可用时她会如实说没看到。面板里「让她画完自己看一眼」关掉、或「视觉能力」选「不支持」时，画完只回一句「画好了」，不会把图给她看。
- **生图构图**：可以让她画方图、竖图、横图或宽幅，也能在「生图」页设置默认构图。工具本次指定优先于默认值；没有指定且默认是「让她选择」时，沿用原来的图片尺寸。四档尺寸分别为 1024×1024、1024×1536、1536×1024、1536×864。自定义接口使用 `{size}` / `{width}` / `{height}` 才会跟随构图，写死的参数仍按接口配置发送；服务不支持尺寸时会如实报错。
- **Codex 订阅生图（实验性）**：在「生图」页选择该接法并登录 ChatGPT，再保存配置。它使用非公开图片端点，可用性、支持的模型和额度由账号、工作区及服务端决定；不是公开 API 兼容性承诺。令牌单独保存在插件数据目录 `codex-auth.json`，不会放进配置或返回面板。登录使用本机 1455 回调；端口被占用时可粘贴完整回调地址，取消 / 超时 / 卸载会关闭本次登录。退出会删除插件保存的登录信息。该接法将所选构图作为提示词引导，实际尺寸由服务端选择，不保证严格比例。
- **她的样子**：「生图」页「她的形象」里导入几张她的图（可以多选），让她发自拍、画她自己时就会照着画。要真的「照着图画」，生图服务得支持参考图（图生图）；不支持的话会退回只按「形象描述」画，像不像看描述写得细不细。描述可以点「看图写一段」让能看图的模型写，也可以自己写。
- **用自己画的图**：画完会告诉她一个「画作编号」（#1 是最新那张）。想拿它换 QQ 头像，说「用画作 #1 换头像」；想收进表情库，说「把画作 #1 存成表情」。编号只在本聊天有效，重启后会重新算（画作文件一直都在）。
- **存刚收到的表情 / 图片**：主人说「存一下刚才的表情」时，她会从本聊天最近收到的图片中取图。每个聊天保留最近 6 张的短期引用，重启后可以恢复；有效期从收到时起算 30 分钟，重启不会延长。图片来源本身已经失效时，需要重新发图。
- **查看自己的 QQ 资料**：主人在 QQ 私聊里提到她的昵称、个性签名或头像时，她可以主动查询当前资料。例如问「你现在叫什么」「签名是什么」「喜欢现在的头像吗」。讨论头像画面时，会把实际图片作为附件提供给当前聊天模型，并附辅助描述；模型不支持看图或查询失败时会如实说明。查询仅限主人私聊，与修改资料的权限分别判断；查询本身不会发图或修改资料。
- **发送自己的当前头像**：主人在 QQ 私聊中说「把现在头像发出来」「发你的头像给我」时，她会用 `qq_send_avatar` 直接发送当前头像图片，无需先识图。试运行不真实发送；网关未确认时不会报告成功。关闭「改资料」模块后，查询和发送头像工具都会撤销。
- **换自己的头像**：私聊里说「用刚才那张图换头像」（你刚发的图），或者画完图说「用画作 #1 换头像」都行。图太大会自动缩到 640 以内再交给网关；缩不了或网关不接受时会如实说明，不会假装换好了。
- **戳一戳**：戳她会有反应，偶尔还会戳回来。
- **语音**：心情到了会发语音条；别人发的语音她会先转成文字再听（群里没 @ 她的语音也会转，她能接上话）。听不懂语音条的话，在「语音识别」页可以加云端识别（SiliconFlow 的 SenseVoice 免费）。想用 Breeze 的音色，在「语音合成」页选「Breeze 语音」，填 Key 和音色 id（能列出音色、查额度、自动领每日额度）；「试听」直接用这一页没保存的设置。想让她说话也用「翻唱」里导入的音色，在面板「语音合成」页开「语音条变声（用翻唱音色）」选一个音色（翻唱环境要先装好；变声失败会用 TTS 原声，不影响发送）。
- **表情包**：会自己收藏群里看到的表情包（普通照片不收），并给每张起个名字。表情的名字和标签能在面板「表情包」页直接改（鼠标移到表情上，点名字或标签，改完点别处就保存）。QQ 表情商店里的商城表情会按原样发，动画由 QQ 自己播。在「表情包」页把总开关关掉，她就一张都不发了。
- **怎么偷表情（三种模式）**：面板「表情包 → 怎么偷」里选。「全都偷」是默认，看到就收；「她挑」只把表情记下来、给她一句轻提示，她喜欢才凭编号收；「只听主人的」只在主人私聊、或这一轮只有主人说话时才提示她收，有别人在场时她不能自己收，要主人发话。两种新模式下，表情会暂存 30 分钟（重启不丢），她可以用 `qq_collect_sticker` 按编号收，也能收自己刚画的图。
- **QQ 小黄脸**：她会在文字里夹 QQ 自带的系统表情（/捂脸 /斜眼笑 /吃瓜 这种），和文字在同一条消息里；别人发来的小黄脸她也认得是哪个。不想要就在「表情包」页关掉「夹 QQ 小黄脸」。
- **空间日记**根据明确可公开的经历和她的当前心情写说说。可见范围沿用 QQ 空间的所有人、好友、部分好友可见、部分好友不可见和仅自己。两个「部分好友」选项需要填写名单。普通日记设为「仅自己可见」时，可以自动配一张当天的画作或表情包。图文日记按你启用的素材来源配图。聊天里让她发说说时，只能在面板设定的范围内发布或收窄为「仅自己」。
- **空间互动**：有人评论她的说说会回（接着回她也会接着聊）；逛好友动态时偶尔点赞、评一句（在「空间日记」页打开）。
- **人声分离模型下不动**：安装会自动换国内镜像、断点续传；还不行就照面板「翻唱」页给的地址用浏览器下好，拖进「音色模型」框。
- **回复防漏**默认开启，可在「聊天」页调整。打开「严格正文标记」后，模型必须把正文包进完整标记。缺标记时最多重写一次。
- **生图备用服务**在「生图」页配置。开启后，主服务限流或不可用时按顺序尝试备用服务。备用服务会收到提示词和参考图。试运行会实际生成图片，可能消耗额度，画作保存到图库。
- **本地接口**：想用自己的 GPT-SoVITS、SD WebUI、自己训练的音色？在「本地接口」页生成模板，照注释改或者「复制给 DSH 的话」让 DSH 改，打开开关就行。
- **翻唱**：用你导入的音色唱歌，做好发语音条（一般两三分钟，开着「翻唱效果」里的拆分、定调会再久一些）。在「翻唱」页一键安装、导入音色；QQ 里跟她说想听什么，或者发 `/sing 歌名`。
- **主动找你**：想你了、有事想跟你说时，她会自己来私聊找你（群里不会）。上次找你你还没回，她不会追着发；你在「心智设置 → 动机与行动」里可以设勿扰时段和每天上限。插件自带的模块不会自己私聊你，刷到的东西都交给她决定。
- **她是自由的**（默认）：她自己的事她自己决定：改资料、发评论、画画唱歌、管表情库、加好友、在群里管人，都不用你开口，也不用向你申请；别人让她做只是请求，做不做由她。面板里「关」掉的功能照样不做。别人说话的那一轮，她仍然不能动你电脑上的命令和文件、不能把你电脑上的文件发出去、不能借她翻你的私聊。想回到「只听你的」，在「访问」页关掉「给她自由」。
- **她用自己的话提醒你**：DSH 里有会话卡在授权上、等你选选项（整个 DSH 都算，「访问」页能按工作区开关）、有人加好友或申请进群、点的歌没唱成，都是她用自己的话跟你说，不是固定格式的通知。和她私聊时要授权，回「确认」批准这一次、「取消」拒绝。
- **顺手贴表情**（默认关，在「表情」页打开）：她可以只看不说话，给消息贴个表情。贴不贴、贴哪种由她：睡着了、讨厌对方、正生对方气不贴；难过的话贴爱心、好消息点赞、好笑的跟着笑。
- **群里给你开本机工具**（默认关，「群聊」页）：选「只有主人」后，你在群里直接跟她说的那一轮她能用命令和文件工具；别人说话的那一轮这些工具整个收走。

### 她是一个人（心智核心）

她的身体、记忆、情绪、性格和关系都在「心智核心」里，不在 DSH 的会话记录里，所以会话换新、被压缩，她本人都不受影响。下面这些都是她自己的，你在面板里能看、能调，但大部分不用管。

- **身体**：会累（聊天、唱歌、画画都花精力）、会困（醒着越久越困，再加上生物钟）、会饿（饭点前后）。困了又到了她的夜里就去睡；睡着时只有你（或者你在「心智设置 → 身份」里允许的很亲近的人）叫得醒她，别人的消息等她醒了再看。和你聊着她会熬一会儿夜，代价是第二天更困。
- **投喂**：在 QQ 里说「给你买了杯奶茶」、发 `/投喂 奶茶`，或在「她现在」页填一个吃的点「投喂」。都是虚拟的。想让她只靠你喂，打开「只靠主人投喂」。
- **情绪和心情**：同时可以有好几种情绪，每种有对象和原因，按研究里各情绪的持续时间慢慢消退；心情由情绪和身体慢慢累积。气是冲着谁的就是冲着谁的，不会撒到眼前的人身上（又气又累时偶尔压不住，越亲近越忍得住）。
- **记忆**：聊天停下来几分钟就记成经历；想起来的会更牢，很久没想起的慢慢只记得大概、最后想不起来（数据还在，「记忆」页能看到、能加强、能删）。每天睡一觉时整理：反复出现的事提炼成「知道的事」、做梦。删掉的记忆从备份恢复也不会复活。想起一件事会顺着联系联想到下一件，越往后越淡；群聊回忆沿用当前会话的可见范围。短句追问会参考同一个会话、同一发言人的近期原话。问她「11 月 3 号我们干嘛了」「上个月聊过什么」，她能按日期想，也能一字不差翻出那天的原话。面板可以加载更多、看来源分布和展开关联。想让检索更准，可以选择兼容接口并开启精排，或在「想起意思相近的事」选择离线中文模型。离线模式会暂停远程精排。模型和运行时随插件分发，加载失败时仍可按关键词查找。
- **内心活动**：醒着又没人找她时，她会自己想事、发呆，冒出想做的事（逛空间、逛热榜、写日记、找你），动力够了才去做，不够就犯懒。装了「本地小模型」（「念头与行动」页一键安装：从官方下载约 18 GB 原版权重、在本机转成约 5 GB 的 4 位版本，原版转完移到废纸篓；放在 `~/Aurabot/mind`，要用时约占 6 GB 内存）时这些念头在本机想、不花钱；没装就用 DeepSeek 想，间隔拉长省钱。她想要一项还没有的权限时会私聊问你，你回「同意 #编号」才算。
- **性格会慢慢变**：她有 19 项性格（爱社交、敢不敢说、同情心、容易担心、依恋……），第一次启动从你的人格卡推出「本来的样子」，**请在「人格与自我」页看一遍、确认**。之后同一种表现在两周里的几个不同日子都出现、而且被正面回应，她才会往那个方向走一小步（每晚睡觉时检查）；离本来的样子越远越难走、越容易回来；你一个人对她的影响有上限（「心智设置 → 人格与自我」）。走得太多面板会提醒你，可以看理由、退回版本。想先观察不生效，打开「影子模式」。
- **她自己改自己**：她想通了可以改人格卡、名字、小名、价值观、爱好、外貌、她的故事，或者写一个「我想变成……」的目标；改完会给你发一条通知（可以关），不需要你同意，你可以在「人格与自我」页退回。年龄、生日、「专一」只有你能改。她对你的称呼一开始是你设的「ta怎么称呼你」，之后她也可以自己换个叫法（什么时候换由她，会通知你，能退回；不想让她改就在「心智设置 → 身份」关掉）；你在面板里改称呼就以你的为准。她还会用自己的话写「我是怎么变成现在这样的」故事。
- **关系**：她按 QQ 号认人（改名、冒充都没用），对每个人有亲近、喜欢、信任、称呼、老梗、不能提的事、心结……每段聊天之后更新；信任掉得比涨得快，很久不联系会变淡。很不喜欢、或有心结的人找她，她多半不想理。别人说过还没结果的事（面试、考试、体检、等通知），她会惦记着，到时候聊天时问一句；问不问、问几次看她多心疼人、和对方多亲近；「关系」页能看到，也能点「不用问了」。「关系」页切到「星图」，能一眼看清她认识谁、谁和谁常在一起。不想让她记某个人，点「以后不记他」（可以连以前的一起移走）或「忘掉这个人」：都先进恢复区，30 天内能放回来。「专一」开着（默认）时，心动、爱慕这类喜欢只给你，别人最多是好朋友；有人反复撩她，她对那个人的好感会下降。你很久不理她，她会想你。
- **年龄和生日**：在「心智设置 → 身份」里填。每年生日按她的时区自动长一岁，她知道自己的生日。没填年龄或不满 18 岁时没有性欲。

### 想让她多会点什么？（「模块」分组）

更多功能可以在面板「模块市场」安装，每个模块的说明在模块库里。

她的每项本事都是一个**模块**，在「已安装」页里：

- **不想要某项本事**：把那一行的开关关掉。比如关掉「生图」模块后，聊天里就不会再调用生图工具。
- **想改某项本事**：点那一行的「复制一份来改」，再点「复制给 DSH 的话」，粘给 DSH，写上你想怎么改（比如「空间日记写短一点，多用颜文字」）。DSH 改完保存，几秒内就生效。
- **想让她学会新本事**：在「新建一个模块」里起个英文名（比如 weather），点「新建」，把自动复制好的话粘给 DSH，写上你想要什么（比如「群里有人问天气，就去查一下告诉他」）。
- **先试试再上线**：「已安装」页最下面的「模拟测试」能假装发一句话、调一个工具，看模块会怎么反应，发出去的东西只显示在面板上，不会真发到 QQ。
- **改坏了**：那一行会显示红色的报错；你改的内置模块坏了会先自动用回原来的。实在不行就打开「安全模式」，你写的东西全部不加载，她恢复原样。
- 你写的东西放在 `~/.dsh/plugins-data/aurabot/modules/`，**升级插件不会动它们**。

## 四、出问题先看这里

> 填模型名：「生图」「语音识别」「记忆」页填好服务地址和 API Key 后，点「获取可用模型」就能从列表里选，不用自己抄模型名（Key 已经保存过的话，框里留空也行）。

> 云备份：「系统 → 备份与恢复」里可以每天自动推到 WebDAV（比如坚果云）或 Gitee 私有仓库，远端只留最近几份；推上去的包里一定有她的心智。WebDAV 还能直接拉回来恢复。

> 有新版本时「概览」会提示，点「立即更新」就行（或者复制命令到终端跑），更新完重启 DSH。

> 换电脑：面板「系统 → 备份与恢复」点「立即备份」，把生成的文件拷到新电脑。新电脑装好 DSH 和 Aurabot 后，把文件拖到同一页（首次设置的向导里也有入口），重启 DSH 后会自动换上设置和数据、重新下载市场模块、放回 QQ 会话。备份里有账号凭证，别发给别人；DSH 自己的设置、QQ 网关登录和抖音、小黑盒的浏览器登录要重新弄。

> 装不上、报错了：先看面板「日志」里的报错和插件版本号；也可以扫 [README](../README.md#联系我们) 里的二维码加 QQ 交流群问，或在 GitHub 仓库开 issue（带上日志和版本号会快很多）。

| 现象 | 怎么办 |
|---|---|
| 她完全不回消息 | 1. 右上角总开关开了吗？试运行关了吗？ 2. 去「连接」看「QQ 网关」是不是「已连上」。 3. 对方在白名单里吗？ 4. 看「日志」标签有没有红字。 |
| 「QQ 网关」一直连不上 | 去「连接」页点「一键诊断」：顺着 OrbStack → SnowLuma 容器 → 远程桌面 → 端口 → 连上 → 登录的是不是机器人号 → QQ 在不在线一项项查，告诉你卡在哪、怎么修。改好后点「重新连接」。 |
| 重启 DSH 后有一阵发不出消息 | 一般不用管。网关暂时连不上时会自动等几秒重试；刚连上那一会儿收到的消息也会补上。日志里看到「网关暂时连不上，…后重试」是正常的；一直重试失败再看上面那行。 |
| 她说 @ 了人，对方却没收到提醒 | 她只认群名片和 QQ 昵称，认不出你手机上给好友设的备注。告诉她对方的群名片或 QQ 号再让她 @ 一次。 |
| 群里她不说话 | 群号在「群白名单」里吗？试试 @ 她。 |
| 某个功能的标签页不见了 | 去「已安装」页看看对应的模块是不是关了。 |
| 翻唱说「读不了某个模型文件」 | 多半是文件权限不对（比如用 sudo 放进去的，属于 root），或者安全软件拦住了。在终端里用 `ls -l` 看看文件属于谁；还不行就把提示里那个文件移到废纸篓，在「翻唱」页重新下载。 |
| 装了自己写的模块后她不对劲 | 「已安装」页打开「安全模式」，你写的模块全部不加载。恢复正常就说明是那个模块的问题，看它那一行的报错。 |
| 语音发不出来 | 会自动改发文字。想要更好听的声音，在「语音合成」页点「安装 edge-tts」。 |
| 回复很慢 | 「模型」标签里把思考强度选「低」；也取决于模型服务本身的速度。 |

## 五、关于账号安全

- 机器人一定要用小号。用 SnowLuma 这类非官方工具有被腾讯限制或封号的风险，主号千万别拿来当机器人。
- SnowLuma 在 OrbStack 容器里单独登录机器人号，和你 Mac 上的 QQ（主号）互不相干。
- 群聊里的大肥鱼没有任何操作电脑的能力；只有和你私聊时，在「完整」权限下才可以。

## 六、桌宠：把「大肥鱼」请到桌面上（小白跟做版）

1.2.0 起桌宠是社区模块：先在面板「模块市场」点安装，「桌宠」页才会出现。

桌宠是一个会待在你屏幕角落的小「大肥鱼」：她会冒气泡，你也可以点她聊天。
不用懂任何技术，全程点按钮就行。

### 第 1 步：打开桌宠页面

打开机器人面板，选择「扩展 → 桌宠」。远端地址也在桌宠页的「跨设备连接」设置。

### 第 2 步：点三个按钮（按顺序）

1. 点 **「下载 / 生成客户端」**——这一步把桌宠程序生成到数据目录，几秒就好。
2. 点 **「安装 Electron」**——桌宠的"引擎"，约 100 多 MB，走国内镜像，**1~3 分钟**，
   期间按钮可能没反应，等提示出现再动。
   - 这一步**不需要你装过 Node、npm 或任何编程环境**：有条件就用 npm 装，
     没有就自动直接下载官方压缩包解开，全自动判断。
3. 点 **「启动桌宠」**——桌面上出现大肥鱼就成功了！
4. （可选）想让她开机就在，把 DSH 设置成开机自启，再开桌宠页里的对应开关。

> 三个按钮都灰着或点了没反应？重启一下 DSH 再试。

### 第 3 步：平时怎么用

- **拖拽**：按住她可以甩到屏幕任意位置，会自己稳住。
- **聊天**：左键点她。
- **退出**：回面板点「停止桌宠」；或者点她在菜单栏（屏幕右上角）里的图标退出。
- 她的心跳（在线状态）在面板「桌宠」页能看到。她主动找你目前走 QQ 私聊。

### 「安装 Electron」失败怎么办（手动安装，进阶可选）

自动安装一般不会失败；npm 那条路失败时插件会**自动改用 zip 直装**，不用再点第二次。
如果反复失败（断网、杀软死拦），可以先试试把面板「桌宠」页的「Electron 镜像」换成别的地址；
还不行就手动来：

1. 用浏览器打开这个地址（整行复制）：
   `https://npmmirror.com/mirrors/electron/45.1.0/electron-v45.1.0-darwin-arm64.zip`
   （Intel 芯片的 Mac 把 `arm64` 换成 `x64`。）
2. 下载得到一个 zip 文件，双击解压。
3. 打开文件夹：在 Finder 里按 `⌘ + ⇧ + G`，输入
   `~/.dsh/plugins-data/aurabot/modules-data/pet/app` 回车。
4. 在里面进入 `node_modules` 文件夹（没有就新建一个，名字原样），把解压出来的文件夹
   改名为 `electron`，整个拖进去。
5. 回面板点「启动桌宠」。

> 前提：第 2 步的「下载 / 生成客户端」至少点过一次（`app` 文件夹才存在）。
