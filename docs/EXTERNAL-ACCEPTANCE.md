# 外部验收清单

这些项目需要真实账号、密钥、硬件或人工 GUI 操作，离线测试只能验证接线、权限和状态转换，不能替代实机验收。

## 1. QQ / OneBot

- [ ] 测试机器人号连接 OneBot v11 网关，`/platforms` 显示已连接且机器人号核对通过。
- [ ] 私聊：白名单内普通消息、命令、引用回复、@、语音、图片、文件、撤回通知。
- [ ] 群聊：白名单、唤醒词、群接话、群管、戳一戳、群文件、群头衔过滤。
- [ ] 断线重连：停网关后消息进入补发队列，恢复后只补一次。
- [ ] 试运行/总开关/调试模式都不会真的发到 QQ。

## 2. Telegram

- [ ] Bot Token 有效，`getMe` 返回机器人身份。
- [ ] 文本、图片、带说明的图片能进入同一套会话。
- [ ] 连续 503 的纯图最终失败不会推进 offset，恢复后能重试成功。
- [ ] 群消息、私聊、回复关系正常。

## 3. 备份与云备份

- [ ] 本地备份生成、ZIP 校验、恢复后重启 DSH 数据一致。
- [ ] WebDAV 上传/下载/删除，错误凭据有明确报错。
- [ ] Gitee 私有仓库首推、增量推送、拉取恢复。
- [ ] 恢复中断后 journal 回滚，下一次启动能继续或清理。

## 4. 模型与付费 API

- [ ] 聊天模型真实回复，用量和费用出现在概览。
- [ ] 生图服务的文生图、图生图、参考图、失败回退。
- [ ] ASR 云端/本地、TTS 云端/本地，语音条能发回 QQ。
- [ ] 向量/精排服务可用，离线向量回退正常。
- [ ] xAI 兼容接口的参考图请求契约与真实端点一致。

## 5. 桌面 GUI 与 DSH profile

- [ ] 面板各页能打开，保存后重载仍生效。
- [ ] 首次向导、权限页、危险命令确认。
- [ ] 插件升级/回退后 profile 能正常重载，版本号正确。
- [ ] macOS 深浅色、窗口尺寸、侧栏和工作台布局。

## 6. 本地推理与创作

- [ ] Mac mini 上 MLX/MFLUX 本地生图。
- [ ] RVC/Applio 翻唱、音色导入、取消后台任务。
- [ ] 人声分离模型、ffmpeg 路径和长任务超时。
- [ ] 大文件上传、磁盘空间不足、下载镜像切换。

## 7. 长期运行

- [ ] 心智记忆跨天写入、睡觉整理、恢复区 30 天保留。
- [ ] 会话映射重启恢复、工作区搬家。
- [ ] 定时任务、主动联系、勿扰时段和每日上限。

## 本地已验证的边界

`npm test` 使用假 DSH、假 OneBot、临时目录和 mock 服务，覆盖 1562 个用例；它不能证明真实平台送达、真实模型质量或真实付费服务可用。上面每一项都应在专用测试账号和隔离 profile 上完成后再对外宣称通过。
