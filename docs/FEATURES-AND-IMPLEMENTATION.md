## QQ 会话与回复

1. **连接与恢复。** OneBot v11 正向 WebSocket 接收事件，HTTP 可选用于动作调用。未填 HTTP 地址时由 WebSocket 调用动作。连接后先通过 `get_login_info` 核对机器人账号，再开放会话。回连可补收最近漏掉的普通文字，覆盖管理员好友私聊及聊天白名单内的好友私聊和群聊。补收保留原始时间并按消息去重，群聊仍走正常回复判断。SnowLuma 或其他兼容网关由使用者部署并登录。 [QQ 渠道](../src/channels/qq/index.js) · [连接诊断](../src/channels/qq/diagnose.js) · [补收](../src/channels/qq/inbox.js)
2. **入站与上下文。** 私聊默认进入对话，管理员私聊自动通过聊天白名单。群聊结合白名单、静音、点名、引用、近期话题和插话预算决策。连发可合并，忙碌中的管理员私聊消息可作为插话交给当前轮。引用先验证会话归属，再附上原文、时间和可用图片。合并转发提供历史上下文，多图按消息与发送者标注来源。 DSH 的本机会话与 QQ 会话用会话映射接起来。 [聊天中枢](../src/chat/hub.js) · [入站解析](../src/channels/qq/convert.js) · [合并转发](../src/channels/qq/forward.js) · [群聊规则](../src/chat/group-policy.js)
3. **会话与模型。** QQ 会话集中在「Aurabot · QQ」工作区。正式和调试模式各记自己的 DSH 会话。权限档位改变、会话被归档、恢复失败或达到心智换会话条件时，可以创建新的会话并衔接近期聊天。模型优先使用该私聊或该群的单独配置，其次是该类会话默认、AuraBot 全局设置和 DSH 默认。切换从该聊天下一轮生效，思考强度收敛到所选模型支持的档位。 [会话中枢](../src/chat/hub.js) · [模型优先级](../src/chat/chat-model.js) · [宿主预设](../cordis.patch.yml)
4. **挂载失败。** DSH 0.2.2-rc.3 及更早版本可能先创建会话、再报告工作区挂载失败。AuraBot 对宿主明确报告的新会话重试挂载，并在保存映射前核对会话仍属于目标工作区。持续失败时保留消息和退避状态，符合条件的新建孤儿交宿主管理。已映射、已归档或归属其他工作区的会话不参与这一恢复流程。 [挂载与退避](../src/chat/hub.js) · [会话恢复用例](../test/system-session-backoff.test.js)
5. **输出与回执。** 回复先检查块类型、输出边界和隐私，再拆成 QQ 文本、引用与点名、语音、图片、表情等消息段。口语清理覆盖管理员私聊和群聊，针对句首空转套话及单纯安抚时重复的饥饿表述。默认发最后一段正文，可开启逐步发出。发送结果区分已确认、排队、试运行和未确认。只有确认送达的内容才登记为已经说过或作为成功经历。断线队列重新检查账号和可见范围后再补发。 [输出解析](../src/chat/reply.js) · [口语清理](../src/chat/reply-style.js) · [断线队列](../src/channels/qq/outbox.js)

管理员可以在 QQ 用 `/silent`、`/active`、`/quiet`、`/chatty`、`/model`、`/remember`、`/reset` 等命令管理聊天。联系人模块处理好友和入群申请，资料模块支持查询及修改昵称、签名和头像。群管理与 OneBot 工具依赖当前会话权限、QQ 账号在群里的角色以及网关支持的动作。 [命令入口](../src/chat/commands.js) · [联系人](../src/channels/qq/features/contacts/index.js) · [资料](../src/channels/qq/features/profile/index.js) · [QQ 工具](../src/channels/qq/features/qq-tools/index.js)

## 语音、媒体与创作

| 能力 | 主流程与接口 |
| --- | --- |
| QQ 语音识别 | 接收语音段后使用 QQ 转文字、DSH `speechToText` 或按配置使用本地脚本、HTTP ASR。需要解码的音频转成模型需要的格式。识别结果带语音标记与发言人进入会话，识别失败仍保留有一条语音的提示。 |
| 语音合成与变声 | 模型可用 `<voice>` 选中要说的段落。TTS 支持 Edge、macOS 系统语音、可配置的 HTTP 接口和本地引擎。本地脚本可覆盖合成，RVC 音色可用于语音变声。语音按 QQ 客户端要求单独发送。 |
| 图片理解与表情 | 收到的图片先下载、分类和限制大小，再通过 DSH 附件接口传给有视觉能力的模型。确认模型只支持文字时以说明代替附图。表情库支持自动或按需收藏、起名、改名、加标签、上传和导入。QQ 黄脸和收藏表情使用各自的消息段。 |
| 绘画与参考图 | 在聊天里直接说想画的内容，由模型调用 `qq_draw_image`。管理员私聊默认可用，其他私聊和群聊从聊天白名单里额外勾选开放生图。参考图可以来自当前聊天最近收到的图、当前引用或允许访问的画作。画成后返回当前会话并登记画作，可选择把成品附件回给模型。 |
| 生图服务 | 支持 OpenAI 兼容接口、自定义 HTTP 接口、实验性订阅接法、自定义本地脚本和内置本地 MFLUX。内置本地部署使用 Qwen Image 2.1，需要 Apple 芯片和 macOS 26 或更新版本。形象图可导入，画自己时结合形象描述和后端所支持的参考图。 |
| 翻唱 | 聊天工具或 `/sing` 提交任务。搜索并取得音源后，按设置裁切、分离伴奏与人声、用导入音色做 RVC 转换并混音，最后作为语音条发回。面板支持装环境、导入音色、调整处理参数和查看进度。 |
| 后台任务 | 生图和翻唱共享任务记录与状态工具。状态包括排队、进行中、正在发送、已发送、已取消、未完成、发送未确认和重启前未完成。取消要求当前会话的发起者确认，正在发送的任务以真实回执为准。 |
| 本地视频 | 配置本地 `video` 脚本后，可从聊天工具启动并把结果发回。具体生成能力由脚本提供。 |
| QQ 空间 | 日记可手动触发、预览、定时或按自主行动配置发布，使用当前可公开材料和时间情绪上下文。可按面板选择可见范围，归档内容、图片和评论。空间互动模块查新评论并按设置处理与好友动态的互动。 |

实现入口。 [语音模块](../src/channels/qq/features/voice/index.js) · [语音收发](../src/chat/hub.js) · [表情库](../src/modules/stickers/index.js) · [生图模块](../src/modules/imagegen/index.js) · [本地生图](../src/features/local-image.js) · [翻唱管线](../src/song/pipeline.js) · [任务记录](../src/core/tasks.js) · [视频模块](../src/modules/video/index.js) · [空间日记](../src/channels/qq/features/diary/index.js) · [空间互动](../src/channels/qq/features/qzone-social/social.js)

## 心智、人格与记忆

- **独立核心和对接层。** `dsh-aurabot-qq/mind` 导出 `createMind()`，接收调用方提供的模型、稳定消息 ID、会话和人物标识。独立 `respond()` 形成草稿，调用方确认送达后用 `said()` 登记。AuraBot 对接层也可分别使用 `perceive()`、`attend()`、`prepare()`，把表达计划、状态和可见记忆交给 DSH。核心使用 SQLite 持久化，收发和调度由调用方负责。 [核心接口](../src/mind/README.md) · [对接层](../src/mind-adapter/index.js) · [存储](../src/mind/store.js)
- **身体、情绪和关系。** 睡眠、精力、饥饿和虚拟投喂由规则更新，影响回应、插话和表达；长时间离线会按生物钟补算睡眠周期，聊天提示只把身体状态转成说话方式，不要求她主动播报。事件评价核对来信原话和来源，可给情绪关联人物及事件；聊天提示只把情绪转成说话方式，不要求她逐条汇报心情。群聊旁听默认只判断是否接话，不把旁听水话记成她的情绪。关系按平台账号持续记录印象、亲近、信任、称呼和待跟进的事。记忆提示只把回忆当背景，要求不复述日期、编号和来源；关系提示只给相处分寸，不把亲近度、信任等档案字段逐项念出来；会带当下的别扭、一起记得的事和在场人的优先级，并放宽到 6000 字、按行截断，避免一条备注无限膨胀；不设总上下文预算。明确问身体或关系时可以用相应的 `mind_*` 工具核对当前状态。 [身体](../src/mind/body/index.js) · [情绪](../src/mind/emotion/index.js) · [关系](../src/mind/relations/index.js)
- **人格与自我。** 私聊预设读取当前人格、自我摘要和私聊规则，普通群聊及受限会话使用公开人格规则。人格卡及自我变化有版本，可查看和回退。渐进特质记录影响来源与证据，有基线和影子模式。宿主每轮通过提示词变量与动态上下文组合适用的状态和规则。其他 DSH 插件追加的系统提示词（例如 dsh-purge 的执行约束）只影响做事方式；人格卡尾部会带一段身份锁定（`{{aurabot_identity_lock}}`），维护段只补执行约束，大肥鱼人设、称呼和语气保持只读；维护插件把注入排到最前时，模型请求出口会把人设块搬回最前。 [人格入口](../src/persona/personas.js) · [预设](../cordis.patch.yml) · [宿主接缝](../src/integration/purge-scope.js) · [性格](../src/mind/personality/index.js) · [自我](../src/mind/self/index.js)
- **记忆形成与查询。** 来信和已送达内容按会话记录。窗口内容可整理为经历，结合时间、事件、人物、重要性和相关候选检索，也可按日期找原话。中文关键词可单独工作，可选兼容在线向量和精排，或用随包的离线中文向量模型。离线模式暂停远程精排。展开编号和关联记忆时按当前会话重新核对可见范围。 [记忆核心](../src/mind/memory/index.js) · [向量与精排](../src/mind/memory/vectors.js) · [离线向量](../src/mind-adapter/local-embedding.js)
- **记忆可见性和删除。** 面板支持按条标记私密、显式分享与撤销，也可设置对指定人物不再记忆或将历史移入恢复区。删除经历会处理可追溯的衍生记忆和性格依据。删除原始聊天记录是独立操作；较早版本缺少来源的状态无法精确回溯。SQLite 确认库损坏时可尝试有效快照，保留坏库副本并重放删除记录。 [对接层](../src/mind-adapter/index.js) · [核心恢复说明](../src/mind/README.md)
- **念头、预算与行动。** 平时的念头可使用按需部署的本地小模型，其他状态评估、深想、睡眠整理和表达按配置选路由。面板显示愿望及行动状态；成功行动会写进经历，聊天提示只给最近做过和心里想做的一两句，选择会在动力接近的几件事之间自然摇摆。预算不足的后台任务可延后处理，启用只在低峰运行的安排时按配置判断；前台聊天单独调度。自主联系、空间、绘画和翻唱沿用模块能力以及相应权限，成功投递或保存后才登记结果。 [内心活动](../src/mind/inner/index.js) · [动机](../src/mind/motivation/index.js) · [预算](../src/mind/budget.js) · [本地小模型](../src/mind/local/runner.js) · [低峰处理](../src/core/offpeak.js)

## 扩展、本地接口与运维

- **模块生命周期。** 模块可注册工具、命令、上下文、规则、事件、定时任务和面板接口。工具按会话挂载，退出时撤销注册。群聊旁听和私聊/被叫到分开计算注意：旁听不会完全停掉她的意识流，等待回复按管理员、私聊、必回、普通群聊排队。可创建自定义副本覆盖内置模块，支持热重载、失败回落和安全模式。社区模块各自声明来源和版本。社区模块按需从本分支模块库安装；上游模块只读参考，实际能力由已安装模块与本机环境决定。 [模块内核](../src/core/modules.js) · [内置清单](../src/modules/index.js) · [社区目录](../src/core/community.js) · [扩展 API](../src/modules/API.md)
- **本地脚本契约。** 工作台可在数据目录 `local/` 生成 `tts`、`asr`、`image`、`song-convert` 和 `video` 的脚本模板。启用后模块按约定调用脚本并读取结果，脚本需自行连接对应软件或 HTTP 服务。用户脚本与官方安装包分开保存。部分本地环境有独立的安装、修复与试运行入口。 [本地接口](../src/local/local.js) · [模板说明](../src/local/templates/README-本地接口.md) · [模块教程](MODULE-TUTORIAL.md)
- **DSH 和程序联动。** 同进程扩展可用 `ctx.get('aurabot')` 读取状态或调用导出的能力。面板可为其他 DSH 会话启用联动工具，也可开启带凭据的 HTTP 开放接口。消息发送沿用目标白名单、运行模式和发送回执，AuraBot 自身会话的工具与联动工具各有使用范围。 [联动服务](../src/core/bridge.js) · [工具挂载](../src/chat/hub.js)
- **文件与授权。** 文件发送按当前轮发言者、目标会话和配置目录核对。跨环境发送可用网关文件接口、编码后的内容或临时中继。群聊可仅给管理员开本机工具，混有他人发言的轮次会收起这类工具。DSH 的授权和问题通知可按工作区配置，管理员可从 QQ 私聊回应符合条件的待处理授权。 [文件中继](../src/chat/file-relay.js) · [会话权限](../src/chat/access.js) · [授权](../src/security/approval.js) · [通知](../src/features/notice.js)
- **宿主维护工具边界。** 宿主插件注册在根作用域的工具（如 `purge_*`）会被社交预设继承。AuraBot 按会话把它们收窄到完整权限的管理员私聊，并在执行入口复核发言人、机器人账号和管理员授权版本；其他会话的提示词仍按 DSH 的设置接收维护插件的追加内容。 [接缝](../src/integration/host-tools.js) · [会话工具闸](../src/chat/tool-scope.js)
- **面板和数据边界。** 宿主接口负责来源、请求类型及配置权限，默认管理限本机访问。运行模式包括正式、试运行、调试和停用。插件数据默认放在 `~/.dsh/plugins-data/aurabot/`，宿主另存 DSH 会话。默认工作区和按需本地环境位于 `~/Aurabot/`。备份可包含设置、模块、记忆、文件和会话，按所选范围打包，可能带凭据。 [宿主管理接口](../src/host.js) · [存储路径](../src/core/store.js) · [备份实现](../src/core/backup.js)
- **日志、用量与恢复。** 面板提供最近活动和各模块的用量统计，费用按配置价格估算。工作区维护入口处理目录迁移、会话健康与归档。支持本地归档、暂存恢复、可选 Gitee 或 WebDAV 云备份，WebDAV 可选仅配置；本机备份、恢复前留底和远端备份均保留最近 10 份。插件更新交给 DSH 的插件管理器；AuraBot 只保留只读的版本说明。 [用量](../src/core/usage.js) · [工作区迁移](../src/core/workspace-move.js) · [云备份](../src/core/backup-push.js) · [版本说明](../src/core/changelog.js)

## 设计沿革、当前限制与待验证

### 原始设计与已落地的接口

原设计把关系、记忆和身体状态放在独立核心里，多个会话共用一个心智。AuraBot 对接层承担 QQ 收发、模型会话及后台调度，核心保留可重用的感知和表达入口。来源隔离、送达后登记、有限的工作记忆、依据可追溯的性格变化和离线回放已对应到源码。到 v1.6.90 已可按会话配置模型，也可选择离线向量。 [设计要点](DESIGN.md) · [当前核心说明](../src/mind/README.md)

### 当前实现边界

- QQ 是当前接入的消息平台。渠道与心智支持带平台的标识，其他平台仍需自己的事件、附件与消息投递实现。使用旧格式的 QQ 会话仍可识别。 [渠道接口](../src/channels/index.js) · [标识格式](../src/channels/ids.js)
- 普通 DSH 会话与 AuraBot QQ 会话可能使用不同预设和模型。插件在管理会话时组装动态上下文并挂载工具；仅从桌面恢复会话时，能否使用这些工具取决于对应实例是否已挂载。长期历史、调试与正式模式会影响模型实际看到的内容。 [会话模型与工具挂载](../src/chat/hub.js) · [DSH 预设](../cordis.patch.yml)
- 真实 QQ 回连、平台扩展动作、图像和音频效果依赖网关版本、模型服务与本机环境。模拟测试和离线回放覆盖路由、状态机、规则、数据隔离和回执等约定。真实提供方的措辞、创作成果及长时间连接表现需要部署环境验证。 [端到端测试](../test/e2e.test.js) · [离线回放](../src/mind/README.md#离线回放)

### 可继续验证和改进的方向

- 用受控测试环境验证工作区冷恢复、账号变更、回连补收与断线补发在各网关上的组合，并核对桌面和 QQ 同一会话的实际模型与工具集合。
- 让创作面板、工具说明和任务回执各自读取实际启用后端的能力与状态，覆盖参考图、尺寸、发送未确认和多个同类任务的查询。
- 继续补齐引用读取降级、旧数据迁移、快照恢复、隐私撤销和扩展热重载的回归用例。扩展新平台前，先验证各渠道的会话归属、附件协议和权限能力。

仓库可用 `npm test` 运行测试。`npm run mind:replay` 与 `npm run mind:privacy` 使用离线场景，分别报告状态演变与记忆可见性结果。 [测试配置](../package.json) · [回放用法](../src/mind/README.md)
